# VIDEO TO ASCII

[![release](https://img.shields.io/github/v/release/beto-group/VideoToAscii?color=brightgreen&label=release)](https://github.com/beto-group/VideoToAscii)
[![license](https://img.shields.io/github/license/beto-group/VideoToAscii?color=blue)](https://github.com/beto-group/VideoToAscii/blob/main/LICENSE.md)

![preview](assets/preview.gif)

*A real-time video to ASCII converter mapping frame luminance to customizable terminal glyphs.*

## 🚀 Features
- 🎬 **Real-Time Processing**: Render local video files frame-by-frame instantly.
- ⚙️ **Custom Parameters**: Fine-tune contrast, resolution width, and X/Y aspect scaling.
- 🎨 **Phosphor Presets**: Custom retro theme colors for the terminal canvas.
- 📥 **Flexible Exports**: Save frames as `.TXT` text files, single-frame `.HTML` scripts, or full interactive HTML video animations.
